# Professor-machine radar encoder–decoder, 100 epochs

Run `bash scripts/run_radar_autoencoder_gate12_professor_100ep.sh` from a pinned checkout. The script pretrains the radar encoder for 25 epochs, builds uncropped clean-LiDAR and geometry caches, trains the radar occupancy encoder–decoder for **100 epochs**, sweeps validation thresholds once, and evaluates the official test at the validation-selected threshold. It runs in the foreground and resumes existing checkpoints under its output directory.

The decoder can predict only within the existing radar encoder grid (`x,y` from −51.2 to 51.2 m; `z` from −2 to 2 m). Radar returns outside that grid are ignored by both the encoder and the gate. A cell is eligible if at least 12 distinct radar voxels lie within a 1.6 m 3D radius. The gate does not exclude cells where faulty LiDAR has surviving returns. Clean LiDAR is the occupancy target, never an inference input.

Every occupancy-training epoch validates on **all 1,296 validation frames** and prints training BCE, validation BCE, exact occupancy IoU, and voxel-center IoU with 0.2 m one-to-one tolerance. Both IoUs use only the gate-eligible reconstruction cells and a fixed confidence threshold of 0.5. The checkpoint named `best_student.ckpt` is selected by the full-validation exact IoU at 0.5. No threshold sweep is run during training. The final validation sweep selects a threshold using validation only, then applies it unchanged to all 2,247 official test frames.

The default output root is `/media/arrubuntu20/EA0A117F0A114A49/sensor_fusion_outputs/radar_encoder_decoder_fullgrid12_1p6m_100ep_20261109`. The epoch records are `radar_autoencoder/metrics.jsonl`, and the final reports are `evaluation/val_best_iou/threshold_sweep.json`, `evaluation/val_best_bce/threshold_sweep.json`, and `evaluation/test/threshold_sweep.json`. To keep a transcript while running, use `bash scripts/run_radar_autoencoder_gate12_professor_100ep.sh 2>&1 | tee "$OUT/train.log"` after setting `OUT` to the desired output directory.
